# TrustShield AI

One Shield Before the Scam.

TrustShield AI is a privacy-first mobile safety layer that protects parents, grandparents, and low-digital-literacy users from scam messages inside SMS, WhatsApp, Gmail, browsers, and QR/payment screens.

## Core Idea

The app uses on-device OCR and Gemma 4 E2B reasoning to classify suspicious messages as Safe, Suspicious, or Dangerous. It gives simple English/Tamil warnings and lets the user alert a trusted family member.

## Privacy

No cloud AI. Sensitive messages are processed locally.
